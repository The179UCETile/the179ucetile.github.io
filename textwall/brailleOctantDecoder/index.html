Wait, what's this?

This is a decoder/encoder for a font named "Braille Octant Mono 2.4" by the user "RenaultFan2026". Apparently the person who created it thinks that it should be used everywhere (so much so that he vibecoded an Our World Of Text clone with the main font being Braille Octant).

The "font" itself is actually a kind of subsitution cipher, NOT a readable font!

You may have realized that the inputs use GNU Unifont. This is because it uses characters from the unicode block Symbols for Legacy Computing Supplement, which is not supported by most systems.
