window properties

unreadAmount

Returns the amount of unread messages (BROKEN)

cel()

Returns the cursor's internal decoration ID.

undoWrite()

Removes the most recent character(s) written in the canvas.

redoWrite()

Adds back the most recent character(s) written in the canvas.

selectedChatTab

Returns the selected chat channel.
Return values:

  • 0: This wall
  • 1: Global
position

???

elem

Holds references to key DOM elements on the website.

accept_nsfw()

Hides the NSFW message. By using this function, you understand that the wall you're about to enter may contain NSFW content.

decline_nsfw()

Declines the NSFW message and go back to the main wall.

printMsg(nick, color, msg, isRegistered, isAdmin, channel, displayNick, timestamp, tag, html = false)

Displays a message in chat only shown to the client.
Parameters:

  • nick: The user who sent the message.
  • color: The username color's internal repersentation.
  • msg: The message to send.
  • isRegistered: Determines if the user is registered or not.
  • isAdmin: Doesn't do anything.
  • channel: The channel to send in.
  • displayNick: Overwrites nick.
  • timestamp: The timestamp (given by Date.now()) when the message is sent.
  • tag: The tag. You can use CSS to style the tag.
  • html: Doesn't do anything.
prsCol(color_name)

A utility to get the index of a color in the color palette.

prsTil(color)

Returns the color name from a color index or array.

colFmt(index, options = {})

Returns the internal repersentation of a color, optionally applying decorations for later rendering.
options:

{
  bold: Boolean,
  italic: Boolean,
  underline: Boolean,
  strikethrough: Boolean
}
prsFmt(color)

Parses a specified color into an object of the color and decorations

writeCharAt(char, color, coordX, coordY, decos, doNotAddToUndoBuffer)

Writes a single character at a specific coordinate
Parameters:

  • char: The character to write.
  • color: The color of the character.
  • coordX: The character's X position.
  • coordY: The character's Y position.
  • decos: The decorations to apply to the character.
    {
  bold: Boolean,
  italic: Boolean,
  underline: Boolean,
  strikethrough: Boolean
}
  • doNotAddToUndoBuffer: Decides if the character will add to the undo buffer or not.
color

Repersents the cursor's color.

ce2()

Returns an Object that contains the infomation of the user's enabled decorations.

writeChar(char, step, ???)

Writes a single character at the cursor position with steps included

flushAmount

The amount of writes to be processed by flushWrites() at once.

setWriteInterval(ms)

The controller that decides how often flushWrites() runs automatically.

cursors

This is an alias directed to w.cursors.

writeBuffer

The current rate (milliseconds) at which the writeBuffer is flushed to the canvas.

flushWrites()

This function is automatically used by setWriteInterval()
Immediately processes and renders all queued writes from writeBuffer to the canvas.

getChar(tileX, tileY, charX, charY)

Returns the character at a specific set of coordinates
Default coordinates will be used
Omiting the parameters will give you the character at the current position

Returns a String or null

getCharDecoration(col)

Returns an Object containing decoration infomation from the internal repersentation of a color

getCharColor(tileX, tileY, charX, charY)

Returns the color of a character at a specific set of coordinates
Default coordinates will be used
Omiting the parameters will give you the character color at the current position

Returns a Number, Array or null

getCharInfo(tileX, tileY, charX, charY)

Returns the information of a character that is at a specific set of coordinates
Default coordinates will be used
Omiting the parameters will give you the character infomation at the current position

Returns an Object or null

getCharInfoXY(x, y)

Returns the information of a character that is at a specific set of coordinates in XY format
Returns an Object or null

XYtoTile(x, y)

Converts XY coordinates to specific Tile coordinates

cursorCoords

Read-only
Returns the cursor's position

cursorCoordsXY

Read-only
Returns the cursor's position in XY format

getTileCoordsFromMouseCoords(instance)

An utility function that turns mouse coordinates into canvas tile coordinates.
Requires an instance from a MouseEvent or an ancestor of it.

getTileCoordsFromMouseCoords(instance)

An utility function that turns mouse coordinates into canvas XY coordinates.
Requires an instance from a MouseEvent or an ancestor of it.

Xr(hexColor, increment)

An utility function which increases all channels of a hex color by a certain amount.
Colors will automatically get turned into a valid hex color.

currentRegionSelection

Holds the currently active RegionSelection.

loadEruda()

Loads Eruda, a developer console for mobile browsers or custom environments

lastTime

Stores the timestamp of the last update or action in the system or world

w properties

w

"w": Main hub or core object of the system

w.currentVersion

Returns the client's version (should usually be "3.0.7")

w.displayNick

Returns the user's display name

w.chatHistory

An Array holding all chat messages

w.events

Returns an Object holding events from w.on callbacks

w.on(eventName, callback)

Creates a listener for a specific event, attaching a callback function that will run whenever the event is emitted.

w.off(eventName, callback)

Removes a previously registered event listener, so the callback will no longer runs when the event occurs.

w.emit(event, data)

Triggers or fires a specific event, optionally passing data to all listeners attached to that event.

w.moveCursor(direction, amount, doNotAutoPan)

Moves the cursor with a specified direction and the amount of characters moved.
direction: "up", "down", "left", "right"

w.moveCursorTo(x, y, doNotAutoPan)

w.tp, but with a doNotAutoPan argument

w.broadcastRecieve(force = false)

This function determines if you can listen to cmd events or not.

w.cmd(data, sendId = true)

Triggers a cmd command. Objects automatically get turned into Strings.

w.setFlushInterval(milliseconds)

Sets how often queued ce/edits in a buffer are automatically processed or flushed

w.changeTheme(type)

Changes your current theme to specified type:
0 - Light
1 - Dark
2 - Custom

w.setPrimaryColor(hex_color_code)

Sets the primary color of the current theme

w.setSecondaryColor(hex_color_code)

Sets the secondary color of the current theme

w.toggleTeleport()

Shows or hides the teleport menu

w.color()

Shows or hides the color

w.settings()

Shows or hides the settings

w.goto(wall, subwall)

Teleports or switches the viewport to another wall/subwall

w.tp(x, y)

Moves the cursor to a specific coordinate

w.cursors

Holds the state or data of all active cursors in the system (Map)

w.redraw

Does nothing(?)

w.renderChunkAmount

Holds the current number of chunks the renderer processes per cycle

w.setRenderChunkAmount(amount)

Sets how many chunks of the canvas should be processed at a time

w.getTheme()

Returns the current theme of the canvas (Object)

w.generateCoords(wall)

Generates the wall's coordinates

w.generateCoordsOld(wall)

Generates the wall's coordinates, using old PRNG

w.chunks

A Map containing all chunks loaded by the client

w.typeChar(char, step, ???)

This is an alias directed to writeChar.

w.socket

Holds the active WebSocket connection for real-time communication
